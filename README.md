# @gammaswap/v2-exchange-sdk

TypeScript SDK for the GammaSwap v2 exchange.

## Requirements

- Node.js 20+
- npm

## Install

```sh
npm install @gammaswap/v2-exchange-sdk
```

## Usage

```ts
import * as sdk from "@gammaswap/v2-exchange-sdk";
```

Submodules are also exported:

```ts
import * as signing from "@gammaswap/v2-exchange-sdk/signing";
```

## Development

```sh
pnpm install
pnpm build
pnpm typecheck
pnpm lint
pnpm format:check
pnpm test
```
